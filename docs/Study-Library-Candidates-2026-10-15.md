## Findings in the supplied bytes

1. **ASV and Brenton have systematic chapter-key defects.** Seventeen ASV books and eleven Brenton books with numbered names have nonsequential chapter keys: ASV `1CO.json` begins at `11`, `2CO.json` at `21`; Brenton `2MA.json` begins at `21`. The bundled parser's lazy book-prefix regex consumes a book-number digit as part of the chapter. Reported chapter and verse totals therefore do not validate reference identities. Rebuild from preserved original source markup using explicit identifiers; do not make ad hoc canonical offsets from these derivatives.
2. **Brenton is incomplete.** The hard-coded book list and 52 supplied book files omit `JOB`. The distributor's [Brenton table of contents](https://ebible.org/eng-Brenton/) includes Job. README/manifest call the edition 1844, while the per-book translation labels and builder say 1851. Edition identity and ancillary material need reconciliation. The installed LXX2012 edition is separately documented in `LXX2012-Edition-2026-10-09.md` and must remain unchanged.
3. **TSK has invalid “intro” records.** There are 64 chapter dictionaries with a `0` entry. For example, `PHM` chapter 1 verse 0 contains “speak … with … Let” material, and `HEB` chapter 1 verse 0 repeats Titus's closing greetings. These cannot be accepted as chapter introductions. The adapter probes verse zero and suppresses broad exceptions; a fresh audit must distinguish valid entries, module indexing behavior, legitimate introductions and unavailable data. Relative references have also been flattened into text; retain the original ThML/reference attributes before resolving them.
4. **ISBE splits ordinary text into false headwords.** `v2-xiii.json` starts within a citation and contains part of a discussion of “compel”; `v1-h-l-e.json` is a short OCR fragment. `v5-pre.json`, the final indexed item, is largely map/image OCR. The README's claim of clean article delimitation is unsupported by these samples. Reconcile article starts, continuations, author signatures and illustrations against scans.
5. **Patristic attribution is unsafe as supplied.** NPNF2 volume 5's builder assigns Athanasius as the default author; sampled entries including “To Eustathia, Ambrosia, and Basilissa” and “To Flavian” carry that label. CCEL identifies the volume as [Gregory of Nyssa](https://ccel.org/ccel/schaff/npnf205.toc.html). Introductory/editorial pieces also appear as work records. The supplied 2,166 count is a count of extracted documents, not a verified count of distinct ancient works.
6. **Authenticity and recension distinctions need explicit fields.** The standalone Apostolic Fathers index labels letters to Tarsians, Antiochians and the Virgin Mary simply as Ignatius. The source includes an [introductory distinction for spurious epistles](https://ccel.org/ccel/schaff/anf01.v.xiii.html). Preserve source-attributed authorship, disputed/spurious status and shorter/longer/Syriac versions rather than flattening them into ordinary author entries. Check the other attribution fields independently.
7. **The Fathers transformations exceed the README description.** README describes selective removal of Coxe notes while keeping identifiable translator notes. `build_fathers.py` instead strips all ANF `<note>` elements and keeps NPNF notes inline, and filters a range of introductions/editorial divisions. The archive's exclusions of Pseudo-Clementines and Apostolic Constitutions are unconfirmed prior editorial choices. Preserve original sources and document every retained/excluded layer before deciding the app's projection.
8. **Bengel is a noisy draft derivative.** The “28 books” count includes `_front`; it is not 28 NT books. The index identifies 18 uncertain boundaries assigned partly by sequence/vote. Philemon contains visibly corrupted Greek/mixed-script OCR. Reader chapter links require source verification, not only an OCR warning.
9. **Provenance is insufficient for reproducible release.** No original EPUB, source XML, SWORD package/config, saved rights evidence or checksum manifest is included. Build scripts contain temporary absolute paths. `resume.sh` downloads moving upstream artifacts, and its downloads do not completely establish the final TSK/Josephus inputs. Do not execute it as the app's build pipeline. The bundle's public-domain statement remains a claim pending exact-artifact and layer evidence, including translation and distribution scope.

## Integration shape if selected

Use existing Library collection navigation and full article/context views. Historical theology, historical background, dictionary entries and patristic works need clear author/translator/edition labels; they are not Ordinary Means commentary or confessional source documents merely because they sit beside those collections. Work titles, source divisions and stable locators should be usable without a guessed Scripture association.

Start with browse and full-text access. Add reader suggestions and packet excerpts only from explicitly parsed, validated source citations, retaining unresolved citations separately. TSK cross-references do not establish quotations, allusions or dependence. ISBE headwords do not establish canonical identities. Future packet excerpts must retain source attribution and stable locators.

Each selected resource needs immutable raw inputs, saved rights evidence, importer and transformation records, an exact source/output manifest, source fidelity checks and a documented successor release. Extend search through a new derivative release; preserve `library-search-2026-10-14-v1` and active v2 pins, including v2 manifest SHA-256 `70017093d90f97ccedd89edbc9d99663c18bd43b52de59bcbc24ab8f56c10a1d`. Measure search and offline package growth before selecting the full Fathers corpus; do not ship duplicate JSON/plain-text renditions without a runtime need.
