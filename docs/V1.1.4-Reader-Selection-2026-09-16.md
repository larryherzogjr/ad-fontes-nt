# Ad Fontes NT 1.1.4 reader selection release

Date: 2026-09-16
Operator: Larry Herzog Jr., publishing as Ordinary Means

## Scope

Version 1.1.4 brings the web reader's persistent in-reading passage selection
to the signed macOS Apple Silicon and Windows 11 x64 desktop packages. Clicking
a verse number or completing a text drag selects the canonical verse range in
the reader, updates its passage URL, and leaves the selected text and verse
numbers marked after the nearby action menu closes. The menu still offers
copying with a reference, edition comparison and Greek exploration. A verse
click copies the complete verse; a text drag can copy only the selected words.

The shared reader source was committed as `4d165d49759c24f4c98076751bc02b993c1bbb95`.
The desktop release increments npm, Cargo and Tauri metadata from 1.1.3 to
1.1.4. The public Downloads page and updater continue to serve the immutable
1.1.3 signed artifacts until exact 1.1.4 artifacts are built, verified,
reviewed and published.

No Scripture, publisher note, Ordinary Means commentary, corpus mapping,
account ownership rule, note API or database schema changes are part of this
release. Private account-backed notes remain web-only.
