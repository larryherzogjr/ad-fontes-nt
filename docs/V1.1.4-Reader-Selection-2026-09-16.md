# Ad Fontes NT 1.1.4 reader selection release

Date: 2026-09-16
Operator: Larry Herzog Jr., publishing as Ordinary Means

## Scope

Version 1.1.4 brings the web reader's persistent in-reading passage selection
to the signed macOS Apple Silicon and Windows 11 x64 desktop packages. Clicking
a verse number or completing a text drag selects the canonical verse range in
the reader, updates its passage URL, and leaves the selected text and verse
numbers marked after the nearby action menu closes. The menu still offers
copying with a reference, edition comparison and Greek exploration. A verse
click copies the complete verse; a text drag can copy only the selected words.

The shared reader source was committed as `4d165d49759c24f4c98076751bc02b993c1bbb95`.
The desktop release increments npm, Cargo and Tauri metadata from 1.1.3 to
1.1.4. The public Downloads page and updater continue to serve the immutable
1.1.3 signed artifacts until exact 1.1.4 artifacts are built, verified,
reviewed and published.

No Scripture, publisher note, Ordinary Means commentary, corpus mapping,
account ownership rule, note API or database schema changes are part of this
release. Private account-backed notes remain web-only.

## Preparation verification

`npm run verify:both` passed against the prepared source: TypeScript checking,
deterministic production generation and build, 74 Node groups, 20 Python
tests, staging of all 13,473 released offline files, the desktop web build
and six offline desktop tests. An offline desktop preview of the 1.1.4 bundle
was checked at John 1: clicking verse 1 selected
John 1:1, retained the action menu and passage URL, and kept both text and
number marked after dismissing the menu. Dragging across verses 2–3 selected
John 1:2–3; that selection survived menu dismissal and reload. The preview
reported no browser warnings or errors.

## Publication gates

The Windows workflow must build and Public Trust sign from the exact source
commit. The trusted Mac must Developer ID sign, notarize, staple and validate
the same version and commit. Both updater signatures and package hashes must
be independently verified. An immutable combined updater staging directory
must identify both platforms and reproduce all hashes. Larry reviews the
exact signed artifacts and updater manifest before publication. A later
artifact-pin commit updates the public Downloads page, versioned installer
paths, host publisher guards and release tests. The host must publish the
approved bytes and report healthy services; independent HTTPS, updater and
rendered checks follow.

The 1.1.3 release remains available and immutable as the immediate rollback
release. M5 pilot and broader MVP follow-on work are unchanged.
