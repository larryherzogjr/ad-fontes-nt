# Ad Fontes NT 1.1.5 synchronized-reader release

Date: 2026-09-19
Operator: Larry Herzog Jr., publishing as Ordinary Means

## Scope

Version 1.1.5 brings the production-confirmed verse-synchronization corrections
to new signed macOS Apple Silicon and Windows 11 x64 desktop packages. When the
optional desktop-width **Sync verses** control is enabled, the pane receiving
the latest real touch, pointer, wheel or supported keyboard gesture remains the
scroll leader. Programmatic follower movement cannot take leadership. On iPad,
touch-driven movement in the compact Scripture reader is coalesced until its
momentum settles, then the taller Greek or edition-comparison pane aligns once
to the settled canonical verse. Right-pane touch scrolling and non-touch reader
scrolling remain immediate.

The three shared synchronization corrections are commits `abc9dee`, `5482cdd`
and `09cf629`. Larry confirmed the final web behavior on a physical iPad before
authorizing the native release. The desktop release increments npm, Cargo and
Tauri metadata from 1.1.4 to 1.1.5. The public Downloads page and updater
continue to serve the immutable 1.1.4 artifacts until exact 1.1.5 artifacts
are built, verified, reviewed and published.

No Scripture, publisher note, Ordinary Means commentary, corpus mapping,
account ownership rule, note API or database schema changes are part of this
release. Private account-backed notes remain web-only.

## Preparation verification

`npm run verify:both` passed against this coordinated version source: TypeScript,
deterministic imports and publications, 76 Node tests, 20 Python tests, the
production web build, staging of 13,473 released files, the desktop web build
and six desktop tests all completed successfully.

An offline desktop preview at 1280 × 800 verified synchronized scrolling in
both directions, including changes of scroll leadership, for Explore Greek and
Compare editions. A 390 × 844 John 1:15 Greek deep link rendered correctly and
keyboard navigation moved to Previous study. The browser reported no warnings
or errors. The same shared synchronization corrections had already been
confirmed on a physical iPad in the production web app before this desktop
release preparation.

## Publication gates

The Windows workflow must build and Public Trust sign from the exact source
commit. The trusted Mac must Developer ID sign, notarize, staple and validate
the same version and commit. Both updater signatures and package hashes must be
independently verified. An immutable combined updater staging directory must
identify both platforms and reproduce every hash. Larry reviews the exact
signed artifacts and updater manifest before publication. A later artifact-pin
commit updates the public Downloads page, versioned installer paths, host
publisher guards and release tests. The host must publish only the approved
bytes and report healthy services; independent HTTPS, updater and rendered
checks follow.

The 1.1.4 release remains available and immutable as the immediate rollback
release. Physical Windows 11 install, upgrade and uninstall acceptance remains
a separate check.
