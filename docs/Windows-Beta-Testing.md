# Ad Fontes NT — Windows beta

A New Testament study environment from Ordinary Means.

This first beta targets Windows 11 on an Intel or AMD 64-bit PC. Windows ARM and older Windows versions have not been validated. It includes seven New Testament editions, Greek tools, comparison commentary, and all 250 Ordinary Means Greek articles. No account or login is required; personal notes are not included.

## Install

1. Extract the supplied ZIP and open the file ending in `-setup.exe`.
2. Follow setup for your Windows user account, then open Ad Fontes NT from Start.
3. Keep `BUILD-INFO.json` with your test notes so Larry can identify the exact build.

The installer includes Microsoft's offline WebView2 runtime installer. A machine missing that runtime may show an additional Microsoft setup step. This is an unsigned beta, so Windows may show an unknown-publisher or reputation warning. Report any warning or installation block to Larry; do not disable Windows security or bypass an organization's policy.

## Try these checks

- Read John 1. Switch editions, change books/chapters, and search for a reference such as Romans 3:23 or a word such as grace.
- Open Compare editions at Acts 8:37. Check that edition differences and commentary are readable.
- Open Ephesians 2:1, choose Explore Greek, select νεκροὺς, and open Larry's Nekros study. Follow its Doulos link, then Return to Greek. Your original selected word should remain available.
- Open Mark 1:4, explore μετανοίας, and read Metanoia. Near the end, follow footnote 1 and its return arrow.
- Disconnect from the internet and repeat reading, search, Greek tools and article cross-links. The original larryherzogjr.com links require internet; the included articles do not.
- Reconnect and use an article's “Open original website edition on larryherzogjr.com” link. It should open your normal browser; the linked article intentionally retains its original translation edition.
- Use Tab, Enter and Escape. Resize the window and try your usual Windows display scaling.
- Change the edition and text size, close the app, then reopen it. Check your reading position and preferences.
- If convenient, install while disconnected from the internet and report whether setup succeeds. Do not remove an existing WebView2 runtime just for this test; other apps use it.
- When finished, uninstall through Windows Settings → Apps. Record any error.

## Send Larry the results

Include the build/commit from `BUILD-INFO.json`, Windows version, Intel/AMD/ARM processor type, display scaling, and whether installation and offline use worked. For a problem, give the passage, edition, steps, expected result and actual result. Screenshots of unexpected behavior are helpful. Keep passwords and other private information out of reports.

There is no automatic updater yet. Larry will supply a new installer for later betas. A successful build is not a substitute for your real Windows test results.

## Application icon

This build uses the approved ivory AF open book with a brass bookmark on navy. Check its appearance in Start, the taskbar, installed-app shortcuts and setup. Report a blank, checkerboard or generic icon, and include the build identity from BUILD-INFO.json.
