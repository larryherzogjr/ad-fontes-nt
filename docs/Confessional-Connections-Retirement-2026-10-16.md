# Confessional Connections retirement — October 16, 2026

AFNT-119 / AFNT-102. Larry requests removing Confessional Connections and all related Book of Concord resources because their reading/integration does not add value. This supersedes the active-feature descriptions in `Confessional-Connections-2026-10-14.md`.

The shared web/desktop Library now has eleven collections. Removed the confessional collection card/switcher destination, English document reader and independent text search, Sources & Editions resource section, Study Packet checkbox/content/citations/count, related runtime loader and unused styles. Old `view=confessions` links resolve to the clean Library overview. Confessional bookmarks/history are hidden without mutating stored device records. Saved packet configurations with `relatedConfessions: true` still load, discard that retired option, and build the remaining packet without requesting confessional data.

Normal imports no longer run the primary-page parser or confessional publisher. A separate cleanup step removes the entire generated `app/public/confessions/` tree, including stale predecessors. The desktop allowlist excludes this collection; desktop preparation recreates its output from scratch, so old payloads are removed there too. The general full-text Library search never indexed this collection: its active v5 inputs, implementation pins and all 234 derivative hashes are unchanged. Existing approved word studies/commentary, including their authored citations, are unchanged. No Scripture/editorial/source text is rewritten.

Original source snapshots, acquisition evidence, manifests, reference parser and historical reproduction tools remain in the repository outside distributable assets. The Book of Concord is no longer available through the app. The Ordinary Means imprint and existing Lutheran/confessional identity are unchanged.

This is a shared source update after the already-frozen 4.3.2 native artifacts. Those signed artifacts and their staged release command are unchanged and do not contain this removal. No new app version, native signing, publication, push or host deployment is performed by this change. Release packaging/publication remains a separate step; this record does not claim that production or installed apps have changed.

Validation passed: `npm run verify:both` completed typecheck, normal imports, 184 application tests, 50 Python/source checks, the web production build, offline frontend build (61,470 released assets) and 19 desktop checks. The first run found a lectionary test expecting the retired checkbox to round-trip; it now checks a retained option, and a separate retirement test checks migration of saved confessional selections. The complete rerun passes. Browser checks against the production build confirm old paragraph/filter URLs show the eleven-collection overview, a Romans 3:28 packet builds without a confessional option/content, keyboard return to collections and chapter navigation to John 2 work, and Sources has no Book of Concord heading or resource links. At 320 pixels, Library and packet scroll width equals the viewport width, and packet controls remain readable. No captured browser warnings/errors. The former v4 index URL returns HTTP 404. Temporary preview servers/tabs were used only for testing; no new signed-native or physical-device acceptance is claimed. Evidence: `artifacts/review/confessions-retirement-2026-10-16/`.
