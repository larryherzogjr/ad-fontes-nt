# Ad Fontes 2.0.0 desktop release

Larry authorized building the macOS Apple Silicon and Windows 11 x64 apps as 2.0.0, followed by verified publication. This major release adds approved whole-Bible English reading, NT/OT connections and reviewed quotation displays, full Septuagint source research/interlinear/concordance, and the approved UX work. Accounts, personal notes and Google OAuth are retired; publisher footnotes, existing Ordinary Means commentary and device-local preferences/bookmarks remain.

The public name/subtitle remain Ad Fontes / A biblical study environment from Ordinary Means. Native product name, bundle/package identifier, executable, signing identities, updater public key/endpoint and approved icons remain unchanged. Platform support remains macOS 14+ on Apple Silicon and Windows 11 x64. Existing 1.1.5 signed downloads/stable metadata remain available until the coordinated new artifacts are verified and published. Predecessor packages are immutable rollback references.

Builds use the same exact private-main source, deterministic pinned imports and checksum-inventoried offline content. Signing uses existing Developer ID / Apple notarization and existing Azure Public Trust / Tauri updater keys. No newly provisioned service or signing identity is required. Secrets remain in existing protected storage and process environment, outside source, logs and artifacts.

Required verification: source tests/typecheck/web and desktop builds; packaged content; OS signatures/notarization; exact updater signatures and hashes; macOS install/upgrade/offline behavior; immutable staging and publication byte verification. Physical Windows install/upgrade/uninstall remains a tester acceptance item; signed CI packaging is not a claim of Windows runtime certification. M5 and overall MVP acceptance remain incomplete.

Native build and artifact verification are in progress. Final source commit, workflow, artifact identities, sizes, hashes and publication results will be recorded below.
