# External link behavior — October 15, 2026

AF-UI-015 implements Larry’s request that all external links open a new tab, prompted by the Book of Concord “Original transcription” link replacing the Library page.

A shared `AppLink` renders absolute HTTP(S), protocol-relative web links and email/telephone handlers with `target="_blank"` and `rel="noopener noreferrer"`. It retains other relationship tokens and removes explicit `opener`. Internal relative routes, fragments and blob downloads keep their existing behavior. Classification is deterministic during server rendering and hydration; it does not rely on a DOM mutation or click-time popup workaround. Absolute public Ad Fontes links, such as installer URLs and packet citations, also open separately; in-app navigation uses relative URLs.

The TSX sweep moved all dynamic or external anchors through this component, including Library collections, confessions, manuscript sources, dictionaries, reader resources, edition/source/rights evidence, authored-study Markdown, search excerpts, lectionary calendars, downloads, policy email links and printable packets. Internal links in those renderers retain their hrefs, click handlers, refs and attributes. Static internal anchors remain plain anchors. Packet HTML saves the already-rendered DOM, so new-tab attributes survive export without JavaScript. Immutable source/editorial Markdown and corpus assets are untouched.

Three regression tests cover URL classification, actual rendered anchor HTML (including overriding an explicit `_self`), and a TypeScript AST sweep rejecting dynamic/external raw JSX anchors anywhere in the app. The existing Library-return source check now accepts the shared component while retaining its Close, return-navigation and mode assertions.

The native HTTPS opener remains unchanged: external websites open in the system browser, while local assets/routes remain inside Ad Fontes. Native identity, signing, updater configuration and opener permissions are unchanged. Browser verification of the offline frontend does not constitute a new signed native-device test. Mail and telephone destinations still depend on the browser/OS handler; their web anchors receive the same new-tab attributes.

Browser evidence includes a real click opening the Apostles’ Creed source in a new tab with the original Library context preserved. Sources & Editions (16 external links), Hebrew article (7), Greek article, installer links and all nine external links in a Job 1:1 packet have no missing new-tab targets. Internal Greek article return remains same-tab. The packet’s exported DOM fragment independently passes an HTML attribute audit.
