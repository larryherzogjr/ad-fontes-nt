# Ad Fontes NT 1.1.3 UX release

Date: 2026-09-15
Operator: Larry Herzog Jr., publishing as Ordinary Means

## Decision and scope

Larry approved the production-source UX refinement set after reviewing it in a
local browser. The release adds the combined passage/search field, recent
passage and study links, per-item Library bookmarks, focus mode, optional
first-use guidance, saved-note verse indicators, study-panel history, the
standard/expanded study-panel toggle, and accessibility, contrast,
reduced-motion, keyboard-focus, phone and desktop refinements.

The rejected resizable desktop study-panel range slider and saved Library-view
feature are excluded. Per-item Library bookmarks remain. No Scripture,
publisher note, approved Ordinary Means commentary, corpus mapping, account
ownership rule, note API or database schema changes in this release.
